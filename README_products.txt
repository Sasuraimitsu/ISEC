【取り扱い海産物の追加・変更方法】

商品は data/products.json を編集するだけで追加・変更できます。
（index.html や script.js を触る必要はありません）

■ カテゴリ（加工度で4段階）
  ichiji  … 一次加工（活〆・氷〆・ドレス・フィレ等）
  niji    … 二次加工（切身・味付け・乾物・選別殺菌等）
  sanji   … 三次加工（調理）（惣菜・調理済み等）
  yoshoku … 養殖
  ※アイコン指定：fish（魚）／snow（冷凍）／pot（調理）／wave（海藻・養殖）

■ 現在の担当（重複確認用）
  心勢水産　　　　… 一次加工
  伊勢志摩冷凍　　… 一次加工／二次加工／三次加工（調理）
  カネウフーズ　　… 二次加工／三次加工（調理）
  養殖漁家（連携）… 養殖

■ 商品を1件追加する例
  {
    "category": ["niji", "sanji"],
    "name_ja": "◯◯の味付け加工品",
    "name_en": "Seasoned XX",
    "desc_ja": "商品の説明を書きます。",
    "desc_en": "Description in English.",
    "member_ja": "◯◯株式会社",
    "member_en": "XX Co., Ltd.",
    "photo": "images/products/xxxx.jpg"
  }

・category は複数指定できます（例：["ichiji","niji","sanji"]）。
  カードにはカテゴリのバッジがすべて表示され、どのタブでも表示されます。
・photo は省略可（省略すると写真なしのカードになります）
・_en を省略すると英語表示でも日本語が使われます
・member_ja に担当会員を明記しておくと、新会員の受け入れ時に
  取り扱い品目の重複を確認しやすくなります
・カンマの付け忘れに注意（最後の項目の後ろにはカンマを付けない）
